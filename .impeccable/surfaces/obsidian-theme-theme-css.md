# Obsidian note theme

Scope: the owner's Obsidian vault theme, generated by `obsidian/theme/build.ts` from the DESIGN.md tokens and the rule files in `obsidian/theme/src/`, delivered as the `.#obsidian-theme` package (`theme.css` with the fonts embedded, plus `manifest.json`), and a companion plugin that renders sequence code blocks. Reading view, editing view (Live Preview and source), app chrome (file tree, tabs, command palette, search, status bar, settings), and plugin panes inherited without breakage. Light and dark at equal quality. Desktop and mobile.

Mode: Read for the note column; Operate for the app chrome.

Audience and job: one researcher reading and writing long Korean notes daily that mix English terms, Latin gene names in italic, DNA and protein sequences, math, code, and tables. Success: long sessions read comfortably, sequences can be counted by position, standard Obsidian wayfinding stays intact, and the theme is recognisable with the content removed.

Sequence rule: GenBank convention. Groups of 10, up to six per line as the reading column allows, a right-aligned tabular start position per line, styled `>` headers, rules between records in multi-FASTA. Each residue sits in a square cell drawn only behind the residues, and the block stays inside the reading column. Any input shape (one long line, 60/70/80-character lines, multi-FASTA, protein) is reflowed. The length badge is the copy control in reading view and Live Preview: a press copies its record as written, or the whole fence for a one-record block, and the badge fills rule blue for a second. There is no copy icon. Inline primers stay ungrouped. Rendered by the companion plugin for `fasta`, `dna`, `rna`, `protein` blocks. The fence names the molecule: a `dna`, `rna`, or `protein` record's length badge opens with a cell naming it, joined to the length, and a `fasta` record names none and reads its unit from the letters. Every badge ends where a full line's last cell ends at the block's line length, so a note's badges share one edge, a short primer's included. The position column is at least three digits wide. Printed parts (top rule, cell lines, badge) are rule blue; the header and residues are ink.

Code rule: at most four token colours derived from the palette; proof red never in code; every token colour passes contrast on the code ground; Prism (reading) and CodeMirror (editing) both themed; checked with nix, python, typescript, bash, yaml/json and Korean comments, light and dark.

Fonts: Source Serif 4 (Latin, italic for gene names, Greek) with MaruBuri for Hangul in one stack for body and headings, D2Coding (code and sequences; Hangul exactly two Latin cells). All OFL, subset to woff2 and embedded in the theme.

Anti-goals: no grid, dots, or texture behind running text or in the margins; no monospace running text; no navigation the reader has to learn; no rounded corners or pills; no one-sided bar on a box; no line marking a change of layer; no change to Obsidian's component sizes and positions.

## Direction contract

THESIS: Hangul and sequences both live one character per cell. The frame is ruled like Korean 원고지 so the monospace blocks and the prose share one cell module; it refuses the category default of a neutral grey theme with one purple accent.

OWN-WORLD: cool paper in three tonal layers: page #FAFAFA, side panels and tab strips #F0F1F3, set-in blocks #ECEDEF (dark #1A1A1A, #1E2025, #23262D), at least 0.025 OKLCH lightness apart and never split by a line. Ink #1A1A1A. Manuscript Rule Blue #0359B0 (dark #9ACCFD) for links, tags, heading markers, and frame rules; Proofreader's Red #B23A30 (dark #E2806F) only for edit marks. Fine rule #D4D7DD inside a layer. Zero radius; the active tab, title rule, and callouts cut one corner at 45° with an unbroken rule; a code block is the set-in tone alone. Square tags; Lucide icons at a 1.5px stroke.

STORY: the reader opens a mixed lab note, reads the Korean body in a calm column, finds a primer by its position number in a gridded sequence block, and moves between notes through the familiar tree, tabs, and outline.

FIRST VIEWPORT: desktop 1440 wide. Ribbon, sidebar tab row, file tree, and vault bar form one #F0F1F3 column; the open note is bold with a red proof caret before its name. The tab strip sits in the same tone with square tab cells; the active tab is page-toned, joins the note, and is cut at its corner. A centred reading column of 700px with the title on a blue rule cut at its end, properties as ruled rows on the cell module, H2s opened by a blue square marker, and a sequence block drawn by the companion plugin on the cell grid.
